# SSC for Web

## 概要

Saitama Sora Cam (SSC) が提供する防災情報Webアプリケーションです。  
YDITS が Saitama Sora Cam 用に制作・ライセンス提供しています。

https://ssc.ydits.net/ で公開しています。

## 利用方法

`src/pages/` ディレクトリをデプロイします。

ゼロビルド・ノーフレームワーク・サーバーレス構成のため、どのような方法でもデプロイできます。
